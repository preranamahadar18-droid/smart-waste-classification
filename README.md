# ♻️ Smart Waste Classification System Using Computer Vision

AI-powered Smart Waste Classification System designed to automatically identify and classify waste images into **Organic Waste and Recyclable Waste** using Deep Learning and Computer Vision. The system helps improve waste segregation, recycling efficiency, and environmental sustainability.

---

## 📌 Project Overview

This project uses Artificial Intelligence and Image Classification to identify different categories of waste from uploaded images. A trained TensorFlow deep learning model analyzes the input image and predicts whether the waste belongs to the organic or recyclable category.

The system provides a user-friendly Gradio interface with image upload functionality, prediction results, and confidence scores.

Key goals:

✅ Automate waste classification
✅ Improve organic and recyclable waste segregation
✅ Support efficient waste management
✅ Promote recycling and environmental sustainability
✅ Reduce manual waste sorting efforts

## ⚙️ How It Works

1. A user uploads an image of waste through the Gradio interface.
2. The image is resized and preprocessed for the trained model.
3. The TensorFlow model analyzes the image.
4. The system predicts the waste category: Organic or Recyclable.
5. The predicted category and confidence score are displayed.
6. The results can help users make better waste segregation decisions.
